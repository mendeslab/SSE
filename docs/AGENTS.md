# Editing this documentation

Read `README.md` in this directory before editing the collection. Its placement and editorial rules
apply to humans and agents alike. Keep explanations coherent, scoped, and mathematically explicit.

Consult relevant mathematical documentation when useful. When an authorized implementation requires
updating existing explanations to remain accurate, make focused edits; do not append a work record.
Do not add changelog entries, task transcripts, raw output, or speculative topic inventories to the
LaTeX documents. Do not turn numerical agreement into a proof, or describe proposals as implemented.
For explicitly authorized exploration documentation, follow the README lifecycle. Its guidance is
not standing authorization to record new decisions or expand exploration histories.

No per-change documentation requirement, provenance ledger, claim registry, or mandatory workflow
is intended. Do not introduce these mechanisms as part of routine maintenance. Compile affected
LaTeX documents and inspect their rendered layout when changing them. Keep generated output under
`build/docs/` at the repository root.

## Permanent development records

Do not create or expand permanent development records unless the user explicitly requests them.
This includes validation reports, benchmark summaries, audit reports, session notes, decision
histories, and changelog entries.

Authorization to investigate, implement, test, or benchmark does not itself authorize preserving a
report in the repository. Existing reports, directories, and previous exceptions do not establish
continuing permission.

Use ignored locations for scratch material and report findings in the conversation. Do not
track scratch material or move it into a tracked directory without explicit authorization.

When an authorized implementation requires updating existing user or mathematical documentation to
remain accurate, make focused edits to the relevant explanation. Do not append a record of the work
performed.

If a permanent record would be valuable, propose its purpose and destination. Do not create it
pending approval.
